PhishGuard ZK

by Naishal & Sruthika

An Advanced AI-Powered Phishing Detector built with Zero-Trust Architecture. Developed collaboratively for the MLH Midnight Hackathon.

Developed under high pressure for the MLH Midnight Hackathon, PhishGuard ZK is a next-generation endpoint security tool engineered to intercept and neutralize phishing threats in real-time.

By seamlessly integrating Zero-Trust Architecture with Machine Learning algorithms, the system aggressively evaluates URLs and DOM structures. It doesn't rely solely on blacklists; instead, it heuristically analyzes page content, compares network requests against known threat patterns, and blocks the user from executing malicious payloads.

Features include real-time threat scoring, decentralized log verification, and a lightweight footprint designed not to bottleneck system performance.

  • AI / ML
  • Zero-Trust
  • Python

Nexus WIP

A modern, heavily customized document editor inspired by Apple Pages. Aiming to compete with giants like MS Word and Google Docs.

Engineered as a high-performance alternative to traditional editors like Microsoft Word and Google Docs. Nexus is a fully-featured rich text environment that prioritizes a distraction-free, cinematic user interface.

Under the hood, the architecture is being built to handle massive document states without input lag or memory leaks. The core engine focuses on modular block rendering, live formatting, and a custom typography engine.

It is currently in active development, pushing the boundaries of what browser-based DOM manipulation and state management can achieve.
